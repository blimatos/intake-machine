Settings & AI key

AI-powered tools need an Anthropic API key. It's stored only in this browser and never written into the file. For real users, use the server-side proxy below instead.

If set, tools call this instead of Anthropic directly, and the key lives on the server.

Production setup — Supabase Edge Function

Edge Functions → New function ai → paste, deploy, then supabase secrets set ANTHROPIC_API_KEY=… and put the function URL in the Proxy field.
